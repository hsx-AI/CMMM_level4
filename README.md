# 电机公司仓储物流自适应优化系统

Vue3 + Three.js + ECharts 的仓储与 AGV 数字孪生前端，支持厂区总览、仓储配置自适应优化、AGV 配送策略自适应优化。

## 技术栈

- Vue 3 + TypeScript
- Vue Router
- Three.js（3D 厂区与模型交互）
- ECharts（图表）
- Vite

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 说明

- 厂区总览：3D 模型 + 车间/仓库详情与仓储分析
- 仓储配置自适应优化：库群分析、优化方案对比、调整指令终端、下发执行反馈
- AGV 配送策略自适应优化：案例切换、策略选择、路径对比与价值举证
